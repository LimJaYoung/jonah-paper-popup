# 웹 제작소 공식 지침

실제 웹 표시: [제작 지침](https://bible-studio-preview-jyoung.jjjh523129468.chatgpt.site/guide.html).

기준 원문은 이 폴더이며, 웹 표시본은 `public/guide.html`입니다. `node scripts/sync-production-guide.mjs`로 표시본과 원문 해시 목록을 생성합니다. 승인 참고 이미지는 기존 웹 제작소의 `/guide-references/`에서 확인합니다.

이번 GitHub 반영 범위는 제작 지침 3.2.6과 표시용 생성기·표시본입니다. 작품 코드·에셋·음성·제작 기록·배포 설정은 포함하지 않습니다. 최종 품질 기준 원문은 [DESIGN_ANIMATION_PROTOCOL](MASTER/DESIGN_ANIMATION_PROTOCOL.md)의 「최종 품질 검수 및 반복 개선」입니다.
