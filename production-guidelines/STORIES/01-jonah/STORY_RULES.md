## 근거와 대본
2026-10-11 기존 작품 기록·DECISION_LOG의 사용자 결정과 현재 story.json을 대조해 분리했다. 정확한 문장은 story.json (`story.json`, PC 원본·현재 웹 사본 미포함)이 원본이다. 대사·배역 참고표 (`JONAH_SCRIPT_CASTING.md`, PC 원본·현재 웹 사본 미포함)는 기존 51발화 추출본이며 현재 타임라인과 대조한다. 이미 받은 현재 대본 로컬 출력 승인을 반복 요청하지 않는다. 구도 재검수는 별개다.

‘나를 바다에 던지세요’ 대사와 ‘바다에 내려놓았어요’ 나레이션은 서로 다른 문장이므로 일괄 치환하지 않는다.

## 배역
기존 아래 배역·한국어 문장 표기는 한국어판 확정 범위다. 영어 배역·제목·화면 글자·대본은 별도 확정하고 공통 장면·원화·연출 결정은 유지한다.
Typecast: 내레이터 나윤, 하나님 권일, 요나 현준, 선장 강일, 왕·사람들 대진. 구형 voices/tts를 확정 배역으로 적용하지 않는다.

## 장면 연출
1. 하나님 부르심/니느웨/반대편 항구. 항구 사각형 부두 삭제, 작은 풀3포기. Y자 길은 한 장, 페이지 중앙에서만 좌우 분할.
2. 반대 방향 배 선택 → 승선 → 발판 회수 → 출항 → 선실 입장 → 수면 → 예고. 씬2에서 폭풍 시작 금지. 출항 범위 책 너비15~20%, 배와 항해 소품 함께 이동.
3. 바람·배 흔들림과 선체 파손 → 짐 내림 → 선장 깨움 → 요나 고백 → 선원 기도 → 요나 입수 → 잔잔해짐 → 기도. 기도 구간에 노 젓기 금지. 구름은 작고 둥근 단층/비대칭. 추가 공중 바람 선은 삭제.
4. 큰 물고기 접근/삼킴/사흘 밤낮. 꼬리와 몸통 분할 경계가 벌어지지 않게 모든 동작을 확인한다.
5. 물고기 배 속 기도. 6. 다시 땅/하나님 말씀 따라 니느웨로 이동; 길 두 겹 금지.
7. 사람들 회개 → 왕이 내려옴 → 왕 대사 → 행동 변화. 왕이 아직 언급되지 않았는데 먼저 서 있거나 대사 후 한참 뒤 등장하면 안 된다.
8. 요나의 못마땅함 → 박넝쿨 자람/그늘 → 벌레가 갉아먹음/시듦 → 해/뜨거운 바람/힘듦 → 하나님의 질문/사람들과 동물. 야자수 금지. 자막은 '요나는 너무나 힘들었어요.' 기존 넘어지는 자세는 사용자 추가 지시 없이 새로 바꾸지 않는다. 햇빛은 머리를 따라가는 점선, 넓은 빛 면 금지.


## 웹 씬 2
도입 후 배 클릭/다음으로 승선 시작. 재진입·다시 재생은 승선 전, 이전은 씬 1 항구 도착. 영상 모드는 자동 진행한다.

## 시각 결정
제목 150%, 제작자 70% 및 제주돌담체 느낌의 제목 원화 유지. 영상 말풍선은 제거하고 하단 자막 한 곳을 사용한다. 웹 자막 16px/모바일 14px, 진행 안내 12px. 영상 32px은 웹 확대 규칙과 별개다. 구도 승인 여부는 제작 기록을 따른다.
구름은 작은 둥근 단층, 왼쪽보다 오른쪽을 작고 낮게 한다. 햇빛은 해에서 머리를 따라가는 황금 점선. 공중 곡선 바람 선과 넓은 빛 면은 사용하지 않는다.

## 게시 시안
영상 제목은 하나님께 돌아온 요나. 게시 제목·썸네일 문구 시안은 요나와 큰 물고기. 게시 승인으로 해석하지 않는다.
