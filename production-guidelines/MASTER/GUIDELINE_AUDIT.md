## 수정한 충돌과 누락

- 언어별 독립 출력: 한국어 출력이 영어 완성을 기다리던 이전 문구를 수정했다.
- 영어 음성 담당: 맥북 직접 생성·실측·연결을 명확히 하고 PC 음성 요청·ACK와 완성본 전달 ACK를 구분했다.
- 언어별 파일 경로: 영어 출력이 한국어 파일을 덮어쓰지 않도록 경로 확인 기준을 보완했다.
- 승인된 로고·제작자 표기: 영어화를 이유로 자동 번역하지 않고 승인된 표기를 유지한다.
- 자동 진행 예외: 요나 씬 2의 승선 입력을 일반 자동 진행 규칙과 구분했다.
- 폭풍 연출: 파도 개선·독립 출렁임, 책 밖에서 들어오는 바람, 파손 이후 짐 투하, 손과 물체 접촉, 실제 무릎 자세, 선장의 문 두드림을 최신 사용자 요청에 맞췄다.
- 위치 수정: 104.70초 요나와 선장 왼쪽 10px 요청은 해당 구간에 한정하고 전체 인물의 공통 위치 규칙으로 확대하지 않는다.
- 모든 세션의 시각 기준 확인을 시작 문서·작업 양식에 연결했다. 실제 이미지를 열어 관찰한 특징을 기록해야 한다.
- 과거 구현·Windows 운영 기록에 적용 범위를 표시했다. 기록 당시 수치와 계정 상태를 현재 상태로 오인하지 않도록 했다.
- 이 사본에 없는 PC 원본 링크는 미포함이라고 표시했다. 미확인 내용을 새 문서로 만들어 채우지 않았다.
