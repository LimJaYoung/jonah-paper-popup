# 06 · 미리보기와 출력 구도 비교

사용자가 검수한 제작실 영상 영역이 유일한 구도 기준이다. 이 문서는 출력 전후의 동일성을 확인하는 절차다. 현재 오류 현황은 IMPLEMENTATION_STATUS.md에 둔다.

## 절대 지켜야 할 구현 규칙
1. 출력용이라는 이유로 책 크기/비율/위치, 카메라, 로고, 제목, 제작자, 자막 크기/위치/줄바꿈을 임의로 변경하지 않는다.
2. 제작실 영상 영역과 출력은 하나의 공통 구도 정의와 동일한 장면 렌더링 경로를 사용한다. 서로 다른 영상용 CSS나 미디어 쿼리로 승인 구도를 덮어쓰지 않는다. 기존 분기가 있으면 영향부터 조사한다.
3. 제작실 메뉴·재생 버튼 제거는 허용되지만 영상 내부 구도를 바꾸는 근거가 아니다. 감상용 별도 페이지를 승인된 제작실 영상 영역과 혼동하지 않는다.
4. 창 크기나 출력 해상도가 바뀌면 승인된 16:9 전체 프레임을 가로·세로 동일 배율로 축소/확대한다. 책 또는 캔버스의 한 축만 늘이기, 임의 크롭, 화면 채우기 금지.
5. 캔버스 CSS 표시 크기, 그리기 버퍼, 카메라 aspect, 캡처 영역, DPR, 인코딩 크기와 픽셀 종횡비를 함께 확인한다. 1920×1080이라는 메타데이터만으로 왜곡 없음/배치 일치를 단정하지 않는다.
6. 위치 수정이 필요하면 사용자가 승인한 화면 근거를 찾고 수정 미리보기를 먼저 제시한다. 기준이 불명확하면 추측해서 새 구도를 확정하지 않는다.

## 출력 전후 비교 절차 — 생략 금지
ko/en 각각 같은 언어·버전·타임라인 시각의 미리보기와 출력 프레임을 비교한다. 언어 간 총 길이가 달라도 되므로 양언어를 동일 초에 강제로 맞추지 않는다. 공통 장면 ID의 대응 행동을 참고하되 언어별 글자·줄바꿈과 구도 검수 증거를 구분한다.

1. 사용자가 검수한 작품/파일 버전/시각/프레임을 기록한다. 기준 캡처와 승인 여부를 보존한다. 과거 잘못된 MP4를 승인 화면 대신 사용하지 않는다.
2. 같은 대사·같은 타임라인 시각의 제작실 영상 영역과 출력 경로 검수 프레임을 준비한다. 전체 MP4 전에 스틸 또는 짧은 검수 클립으로 검증한다.
3. 양쪽을 동일한 1920×1080 좌표로 비교한다. 책 바깥 경계의 폭·높이 비율과 위치, 제목/로고/제작자 경계, 자막 기준선/하단 여백/줄바꿈을 수치와 나란히 놓은 이미지로 확인한다. 인코딩 미세 색차를 위치 차이와 혼동하지 않는다.
4. 표지·펼친 책·각 장면·페이지 전환 중간·긴 자막 두 줄을 확인한다. 장면별 확대나 자막 잘림이 있으면 불합격이다.
5. 차이가 있거나 근거가 없으면 상태는 미해결이다. 임의로 허용 오차를 넓혀 통과시키거나 “똑같다/정상이다/최종 완료”라고 말하지 않는다. 불일치 항목을 기록한다.
6. 사용자가 먼저 검수하도록 요청한 작업은 수정 미리보기와 비교 결과를 보여주고 확인 후 전체 MP4를 만든다. 작품별 현재 확인 상태는 PRODUCTION_NOTES.md에 기록한다.
7. 확인 후 전체 MP4를 출력하고 그 실제 파일에서도 동일 시각 프레임을 추출하여 다시 비교한다. 렌더러 설정 확인만으로 끝내지 않는다. 승인본을 검증 안 된 출력으로 덮어쓰지 않는다.
8. 자동 검사/프레임 비교/전체 시청/전체 청취/사용자 승인 여부를 각각 기록한다. 로딩 화면은 한 프레임도 포함하지 않는다.


## 완료 증거
같은 시각의 비교 이미지와 책 경계·자막 기준선 측정값, 확인한 구간, 사용자 확인 여부를 작품 기록에 남긴다. 문서 규칙은 자동 비교·차단 기능 구현을 의미하지 않는다.
