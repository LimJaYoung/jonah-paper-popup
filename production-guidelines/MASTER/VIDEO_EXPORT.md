# 06·07 · MP4 출력과 파일 검수

## 출력 전 조건
한국어는 PLAYBOOK 01~03과 13의 배포·송신·PC 수신을 확인한 뒤 06에서 독립 출력한다. 영어는 04~05와 해당 언어의 13을 확인한 뒤 독립 출력한다. 한국어 출력은 영어 완성을 기다리지 않는다. 한국어 완성 기준 확정은 실제 최종 MP4에 대한 08 사용자 검수·09 언어별 최종 승인·10 공개 클릭을 대신하지 않는다.
실제 음성·대본과 QA_CHECKLIST.md, LAYOUT_PARITY.md의 비교 결과를 확인한다. 해결되지 않은 구도 문제를 남긴 채 정상 최종본으로 출력·전달하지 않는다. 현재 요나의 재출력 조건은 작품 PRODUCTION_NOTES.md를 따른다.

## 언어별 산출물

한 작품의 공통 장면·자산과 언어별 설정으로 ko/en을 각각 출력한다. 두 언어마다 완성 MP4, 해당 영상 시간과 일치하는 SRT, 해당 언어 제목의 썸네일, 게시 제목·설명을 준비한다. 파일명은 `작품명_ko_버전.mp4`, `작품명_en_버전.mp4`처럼 작품명과 ko/en을 포함하고 SRT·썸네일·게시 정보 파일도 같은 기준으로 구분한다.

영어판은 대사·자막·안내의 언어 혼입·잘림·누락을 검사한다. 승인된 로고·타이틀 원화와 J.영 표기는 양언어에서 재사용하며 임의 번역·교체하지 않는다. 별도 게시 제목·설명·썸네일 문구는 해당 언어의 확정안을 따른다. 현재 final.mp4·ko.srt 고정 경로는 기존 구현 설명이며 언어별 자동 출력 지원을 뜻하지 않는다. 미지원 상태에서 영어 작업으로 한국어 파일을 덮어쓰지 않는다.

## 실행 순서와 설정
1. 사용자 최신 출력 지시와 대본 승인 해시/전체 실제 음성 상태 확인. source.reviewed/approval이 낡으면 이유를 확인한다. 검사 우회나 문구만 바꿔 승인 조작 금지. 현재 사용자 지시와 작품별 확인 상태를 따른다. 로컬 출력 허가와 공개 허가를 구분한다.
2. 제작실에서 선택 언어의 대본·실제 음성·동작·구도·전체 시청·청취를 확인하고 근거를 입력한다. 현재 버전과 다른 검수 기록으로 최종 출력할 수 없다. 웹 최종 출력 또는 `node scripts/studio.mjs render --id <id> --lang ko`를 사용하며 영어는 `--lang en`이다. `--preview --seconds 12`는 임시 검수본이며 승인/최종 작품 완료와 구분한다.
3. 1920×1080 viewport, deviceScaleFactor2로 3840×2160 렌더, 무손실 PNG, FFmpeg Lanczos로1920×1080 축소, libx264 CRF16/fast/yuv420p, AAC192kbps,30fps,faststart.
4. CDP Page.captureScreenshot(format png,optimizeForSpeed true)로 무손실 고속 캡처. Chrome 배율 차이는 첫 PNG 크기를 실측한 뒤 clip.scale을 보정하여 다시 캡처한다. 낮은 해상도 이미지를 늘리지 않으며 매 프레임 3840×2160 검사를 유지한다. Playwright screenshot에 지원되지 않는 속도 옵션을 넣는 것만으로 효과가 있다고 생각하지 않는다. JPEG94/CRF18/1x는 예전 방식이며 되돌리지 않는다.
5. assets·글꼴·이미지 decode·window.studio.ready·#loading 제거 확인 후 seek(0). 매 프레임 n/30 seek 후 캡처, 로딩 UI 있으면 실패시킨다. 실시간 화면 녹화나 버튼 자동 클릭 금지.
6. 최종 파일은 `<id>_<ko|en>_<시각>.mp4`이며 검증 전에는 `.part.mp4`다. 기존 final.mp4는 보존한다. 코덱/크기/길이 검사와 전체 디코딩 성공 후 이름을 확정하고 파일 SHA256·대본·검수 버전을 기록한다. 한국어는 기존 output, 영어는 languages/en/output을 쓴다. 실행 중 중복 렌더 금지. 종료 시 이 작업 PID/부모/명령/출력만 확인하여 종료한다.
7. ffprobe 코덱/크기/길이/프레임/음성 확인, 전체 ffmpeg 디코딩, 수정 구간 실제 프레임 확인. ko/en 최종 MP4를 각각 처음부터 끝까지 실제 시청·청취한다. 오류 수정 후 해당 장면과 앞뒤 전환을 다시 검수한다. 전체 시청·청취는 별도. 샘플만 본 뒤 전체 검수 완료라고 하지 않는다.
8. Downloads에는 날짜 붙인 파일을 저장해 예전 MP4와 구분. 웹 수정은 MP4 자동 갱신이 아니다. 링크는 실제 존재하는 절대경로를 제공한다.

## 전달
웹을 고쳐도 기존 MP4는 바뀌지 않는다. 작품명·ko/en·날짜/버전이 구분되는 실제 파일과 언어별 검사 결과를 전달한다. 두 언어 최종 출력 검수와 08 사용자 최종 영상 검수·09 언어별 최종 승인이 끝나야 영상 제작 완료로 보고한다. 자동 검수 통과를 사용자 승인으로 간주하지 않는다. 승인 이후 파일 변경은 07~09 재검수·재승인 대상이다. 게시 완료는 별도로 기록한다. 전체 시청·청취를 하지 않았으면 명시한다. 구도 비교 증거와 미완료 사항은 HANDOFF.md 양식으로 남긴다.


## 현재 코드와 별도 검수
렌더러는 요나/노아 어댑터만 허용한다. 새 작품은 연결을 먼저 구현·검수한다. source/approval 및 음성 준비 검사만으로 단계 01~05와 출력 전 구도·전체 시청/청취가 자동 검증되지는 않는다. 전체 디코딩도 별도 수행한다. 자세한 한계는 IMPLEMENTATION_STATUS.md를 확인한다.
