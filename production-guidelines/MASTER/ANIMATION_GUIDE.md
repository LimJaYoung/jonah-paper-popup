# 01·05 · 종이 동작과 언어별 타임라인

작업 시작 시 [디자인·애니메이션 공통 기준과 이미지 미리보기](DESIGN_ANIMATION_PROTOCOL.md)를 실제 이미지와 함께 확인한다.

제작 순서·통과 조건은 `PRODUCTION_PLAYBOOK.md`를 따른다. 아래 구조는 01-B 대표 장면 시험에도 적용한다. Three.js 상태 컨트롤러와 절대 시간 구조를 재사용하며 전체를 임의로 다른 애니메이션 라이브러리로 다시 쓰지 않는다.

## 1. 페이지와 종이는 함께 움직인다

1. 오른쪽 페이지가 책등을 중심으로 왼쪽으로 넘어간다.
2. 기존 종이는 해당 페이지에 부착된 채 페이지 회전에 맞춰 접힌다.
3. 다음 종이는 접힌 상태로 페이지에 부착되어 있다가 회전에 맞춰 펼쳐진다.
4. 페이지·양쪽 종이의 접힘은 하나의 전환 진행값으로 연결한다. **접기 완료 → 빈 페이지 넘기기 → 새 종이 펼치기**라는 독립 세 구간으로 대체하지 않는다.
5. 책·카메라는 유지한다. 장면 전환마다 책 전체를 닫지 않는다. 마지막은 계획된 종이 접힘과 책 닫힘으로 끝낸다.
6. 이전 방향에도 같은 구조를 역으로 적용한다. 전환 중 중복 입력을 잠그고, 일시정지·재개는 페이지와 종이에 함께 적용한다.

같은 펼침면 안의 다음 사건은 책장을 넘기지 않고 계획된 연속 동작·가림·부품 교체로 연결한다. 장면과 펼침면 대응은 01에서 확정한다.

## 2. 음성·자막·행동이 끝난 뒤 전환한다

PLAYBOOK 03 한국어 완성 확정 후 04에서 확보한 영어 실제 음성을 기준으로 05 영어 동기화를 수행한다. 한국어 원본의 종이책 디자인과 애니메이션의 내용·구조는 유지하고 영어 실측에 필요한 시점·길이만 언어별로 관리한다.

공통 장면 ID·순서·종이 구조는 공유하고, 동작 시점과 장면 길이는 ko/en 별도 타임라인으로 관리한다. 해당 언어의 발화별 실제 음성 길이를 사용하고, 등장·손 내밀기·기도·귀환 등의 동작을 해당 말의 실제 시점에 맞춘다. 문장 내부 의미를 무시한 비율 애니메이션만으로 통과시키지 않는다.

전환 가능 시각 = `max(마지막 음성 종료, 자막 읽기 완료, 필요한 동작 종료) + 해당 장면의 감상 여유`.

자동 재생에서는 완료 조건을 만족하기 전 다음 사건으로 넘기지 않는다. 웹 재생은 실제 음성 종료와 동작 완료를 확인한다. 오프라인 렌더는 검증된 실측 길이·동작 종료 시각으로 같은 경계를 재현한다. 배경음은 끝없이 이어질 수 있으므로 배경음 종료를 기다리지는 않는다.

책장 전환 전에 이전 장면의 발화를 끝내고, 전환 중 다음 장면 음성이 먼저 재생되지 않도록 한다. 한국어·영어의 총 길이를 맞추기 위한 음성 배속·문장 잘라내기는 금지한다.

검수용 seek는 원하는 프레임으로 이동하는 기능이다. seek 성공으로 자동 재생의 종료 조건이 검증됐다고 보지 않는다. 음성을 강제 중단하는 장면 탐색은 정상 자동 진행과 구분한다.

## 3. 종이 인형·소품의 연기

- 팔: 소매·어깨가 이어지고 중간 자세에도 구멍·겹침·피부 분리가 없어야 한다. 요나 `sleeve.js`를 재사용할 때 `updateTorso`는 렌더 전에 수행한다. 새 원화의 앞뒤 UV·관절을 별도로 확인한다.
- 몸: 주저앉기·일어서기·기도는 종이 부품과 필요한 자세 원화로 구현한다. 몸을 단순 압축하거나 옷을 찢어 보이게 하지 않는다.
- 이동: 인물과 받침이 함께 움직인다. 문으로 들어가면 벽 뒤에 자연스럽게 가린다. 갑자기 사라지는 것만으로 입장 동작을 대신하지 않는다.
- 파도·배: 앞/중간/뒤 종이 파도와 배·돛이 연결된 움직임을 보인다. 배 일부는 앞 파도에 가리고 책 밖으로 이탈하지 않는다.
- 물속 인물: 아래로 이동시키기만 해 책 밑으로 비치지 않게 수면 가림을 확인한다. 재진입 때 올바르게 복원한다.
- 연결 소품: 물고기 꼬리, 새 날개, 부리에 문 잎 등의 연결부를 시작·중간·끝에서 확인한다.
- 강조: 주변 동작을 줄이고 감상 시간을 확보한다. 카메라 이동·확대·화면 회전을 사용하지 않는다.

## 4. 재생과 재현성

언어 변경 시 제목·화면 글자·음성·자막·동작 시점·장면 길이·책장 넘김 시간 전체가 함께 바뀌어야 한다. 텍스트만 교체하거나 반대 언어 음성/타임라인을 남기지 않는다. 이 동작은 구현·검증할 요구이며 문서 반영만으로 지원 완료가 아니다.

같은 언어와 버전에서 같은 `window.studio.seek(t)`는 탐색 순서와 관계없이 같은 상태여야 한다. 프레임 수·누적 회전·매번 달라지는 난수에 의존하지 않는다. 재진입과 처음부터는 초기 상태를 복원한다. 음성·자막·종이·페이지를 함께 정지·재개한다.

영상은 추가 입력 없이 마지막까지 진행한다. 웹은 왼쪽 이전·오른쪽 다음 화살표를 고정하고 재생 조작은 아래에 둔다. DOM/Tab 순서도 화면과 맞춘다. 전환 중 중복 동작을 막고 마지막 다음은 비활성화한다. 요나 씬 2의 승선 클릭은 요나 웹 모드 전용 예외이며 새 작품이나 영상 모드로 복사하지 않는다.

## 5. 검수와 현재 구현의 한계

변경한 모든 페이지 전환 0·25·50·75·100%, 역방향, 앞뒤 탐색, 중간 자세, 실제 연속 재생을 확인한다. 종이가 페이지에 붙어 있는지, 이전 장면이 남는지, 책과 따로 노는지를 본다.

현재 `timeline/index.js`는 `story.scenes`마다 turn을 넣는다. `cue-sequence.js`는 별도 계획 모듈이고 실제 플레이어 연결은 미완료이며 기본 19장면 값을 가진다. 또한 접기·넘기기·펼치기 분리 구간을 만든다. **이 파일을 그대로 연결하면 위 동시 접힘 기준을 충족한다고 가정하지 않는다.** 새 작품에 맞는 연결과 검수가 필요하다. 문서의 요구와 구현 상태는 `IMPLEMENTATION_STATUS.md`에서 구분한다.

요나 전용 장면 순서·점선 햇빛·구름·반려 연출은 `STORIES/01-jonah/STORY_RULES.md`를 읽는다.

언어별 단계에 `actionStartSeconds`/`actionEndSeconds`가 명시되면 해당 단계 안의 실제 초 단위로 종이 동작을 보간한다. 미지정 단계는 승인된 기존 비율을 유지한다. 타임라인은 음성·읽기 구간과 명시된 동작 종료 중 긴 쪽까지 유지한 뒤 감상 여유를 더한다. 이 값은 실제 문장 재생을 보며 조정하는 수동 지점이며 자동 의미 인식 결과가 아니다. 같은 펼침면의 연속 사건은 기존 steps로 유지하여 불필요한 turn을 추가하지 않는다.

장면의 선택적 `targetDurationSeconds`는 책장 전환을 제외한 전체 길이다. 기존 각 단계의 음성·읽기·명시 동작 종료·감상 여유를 합친 최소 길이보다 길 때에만 마지막 단계 끝을 연장한다. `contentDuration`에 원래 동작 구간을 보존해 요나·노아 플레이어 모두 기존 시점에 동작을 끝내고 이후 여유를 둔다. 더 짧은 목표가 있어도 최소 길이는 유지한다. `sceneTimings`는 목표·최소·실제 길이를 구분해 편집 화면에 제공한다. 영어 overlay의 scenes에 독립 저장하며 한국어 목표 시간을 영어로 상속하지 않는다. 미지정 작품의 기존 타임라인·구도·음성은 유지한다.

## 6. 새 스타일의 종이 접힘 품질 · 2026-10-17

- 자산마다 부착 페이지·받침·접힘축·앞뒤 면을 기록한다. 책등을 가로지르는 바닥은 좌우 페이지로 나누고 펼친 상태에서 무늬를 연결한다.
- 페이지 → 접힘축/받침 → 장면 → 인물 관절을 연결한다. 기존 공통 전환 진행값과 접힘축을 재사용한다. 오른쪽 페이지가 책등을 축으로 왼쪽으로 넘어가는 동안 기존 종이는 부착된 채 접히고, 다음 종이는 처음부터 접힌 채 부착되어 함께 펼쳐진다.
- 각 종이 부품은 자기 접힘선을 중심으로 연속 회전한다. 전체 시안을 한 장의 판처럼 눕히거나 높이 축소·알파 소거·순간 교체로 접힘을 대신하지 않는다.
- 접히는 각도에 맞춰 종이 앞뒤 면, 얇은 두께, 겹친 가장자리, 접촉 그림자와 차폐가 보이게 한다. 관통·검은 틈·깜박임·뒤집힌 인물이 생기면 수정한다.
- 종이의 미세한 휘어짐과 접힘선 음영은 보조 효과로 사용할 수 있다. 고무처럼 늘어나거나 과하게 튀는 탄성은 피한다. 펼침 완료는 부드럽게 감속한다.
- 책의 형태·크기·위치와 카메라는 고정한다. 빈 페이지를 먼저 넘기거나 책 전체를 닫았다 여는 전환으로 바꾸지 않는다.
- 인물·짐·파도·물방울·바람은 같은 장면 시계로 제어한다. 전환 중 효과가 이전 장면의 잔상으로 남지 않게 수명과 가림을 연결한다.
- 정방향/역방향 각각 0·25·50·75·100%를 실제 브라우저에서 확인한다. 절반 접힘에서 일시정지→재개, 이전→재진입, 임의 탐색, 중복 입력 차단을 확인한다.
- 스타일 이미지 등록은 접힘 구현 완료가 아니다. 접힘 검수에는 실제 중간 프레임과 확인한 코드 버전을 남긴다.
