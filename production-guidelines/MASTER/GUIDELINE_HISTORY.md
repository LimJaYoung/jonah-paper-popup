## 2026-10-17 참고 이미지 해상도 정정

사용자가 지침 이미지의 흐림을 지적했다. 스타일 참고 11장의 640px JPEG를 원본 해상도 무손실 WebP로 교체하고 원본과 RGBA 픽셀 일치를 검사한다. 배포 용량은 이미 무손실 WebP로 제공되는 중복 PNG 5개의 빌드 출력만 제외해 확보한다. 추가로 기존 인물·배경 아틀라스 9개도 RGBA 픽셀이 일치하는 무손실 WebP로 제공한다. PC 원본은 보존한다.

### 기존 문구와 새 요청의 차이·처리

| 차이 또는 충돌 | 이번 통합 | 남은 확인 |
|---|---|---|
| 기존 절차에는 영어 대본 준비가 초기 대본 단계에 포함됨 | 사용자 요청대로 한국어 전체 검수·완성 확정 뒤 04로 이동. 번역·용어·배역·실제 음성 품질 기준 보존 | 기존 영어 자료는 삭제하지 않으며 확정 한국어와 대조 |

| 영어 자동 제작 요구와 현재 자동화·유료 호출 제한 | 요구 절차와 구현 상태를 분리. 기능이 없거나 비용 승인이 없으면 확인 대기/실패로 기록 | 자연어 AI 차단·추가 유료 호출 금지는 그대로 유지 |

위 차이는 사용자에게 보고하고 요청이 명시한 시점·조건만 통합했다. 영문 브랜드·음성 제공자·배역·유료 실행·작품별 출력 허가처럼 이번 요청으로 확정되지 않은 선택은 확인 대기로 남긴다.
