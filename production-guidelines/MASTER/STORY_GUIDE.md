# 01 · 대본과 장면표 작성 방법

제작 순서·통과 조건은 `PRODUCTION_PLAYBOOK.md`의 01을 따른다.

## 본문과 문장

작품 ID·제목·성경 책/장/절·대상·핵심 메시지를 기록한다. 본문의 사건 순서와 화자를 확인하고 어린이가 알아들을 한국어로 재서술한다. 성경에 없는 대사·대표 동물 종류·세부 몸짓은 연출임을 구분한다. 직접 인용할 때는 번역본과 이용 조건을 확인한다.

누가 무엇을 하는지 구체적으로 쓴다. ‘다른 사람을 괴롭혔어요. 하나님은 이런 모습을 보시고 마음이 아프셨어요.’처럼 의미와 주체가 분명해야 한다. 같은 표현의 연속 반복, 불필요한 설명, 본문과 다른 인과를 피한다. 도입에서 이야기와 연결되는 짧은 질문이나 문장을 사용하고, 빈 페이지를 이유 없이 넘기지 않는다. 이미 확정된 마무리에 임의로 새 질문을 추가하지 않는다.

확정 대본을 검토하는 작업에서는 문장을 몰래 윤문하지 않는다. 문장 제안은 기존 문장과 구분해 보여준 뒤 확정된 내용을 반영한다.

## 한국어 확정과 영어 대본

한국어 대본을 성경에 근거해 먼저 확정한다. 영어 대본·음성 자동 제작은 PRODUCTION_PLAYBOOK 01~03의 한국어 전체 제작·검수·최종 완성 확정 후 04에서 시작한다. 한국어 대본 확정만으로 영어 제작을 앞당기지 않는다. 확정된 한국어 완성 버전을 기준으로 영어를 작성한다. 영어는 어린이가 듣고 이해하기 쉬운 짧고 자연스러운 문장으로 쓴다. 번역 중 사건 순서·의미를 바꾸거나 성경에 없는 사건·대사를 임의로 추가하지 않는다. 인물명·지명의 ko/en 표기와 발음을 작품별 용어표로 통일한다.

양언어는 동일 장면 ID를 사용하고 각 장면의 나레이션·인물 대사를 대응시킨다. 발화 분리가 달라지면 대응 관계를 명시해 누락을 검사한다. 영어 원본 버전·대응 한국어 확정 버전과 번역 검수 근거를 기록한다.

## 장면표 형식

| 장면·펼침면 | 발화 ID·화자 | ko/en 정확한 나레이션/대사·언어별 발화 대응 | 보이는 종이 | 시작 → 핵심 → 끝 동작 | 동작을 맞출 말 | 다음 연결 |
|---|---|---|---|---|---|---|
| [번호·면 ID] | [고유 ID·화자] | [확정 문장 그대로] | [인물·소품·배경] | [주체·부품·방향·종료 상태] | [문장 내 구절; 실측 시각은 음성 후] | [같은 면 연속 / 페이지 넘김 / 마지막 닫힘] |

‘자연스럽게’, ‘생생하게’, ‘가까이 보여준다’만으로 동작을 지시하지 않는다. 예: ‘노아가 주저앉은 사람 옆으로 이동한다 → 팔을 앞으로 내민다 → 상대가 손을 잡고 일어난다 → 두 사람이 선 자세로 멈춘다.’ 책과 카메라는 움직이지 않는다.

## 장면·펼침면·발화의 차이

- 장면: 이야기의 사건 단위. 사용자가 확정한 순서와 수를 지킨다.
- 펼침면: 종이가 세워지는 물리적 책의 면. 여러 이야기 장면이 같은 펼침면에서 이어질 수 있다.
- 발화: 나레이션 또는 대사 한 구간. 한 장면에 여러 발화가 들어갈 수 있다.

셋의 수가 같아야 하는 것은 아니다. 어떤 사건에서 책장을 넘기는지 별도 표로 확인한다. 확정되지 않은 펼침면 배치안은 ‘제안’으로 표시한다.

## 문장 원본과 변경

`STORIES/<id>/story.json`은 기존 한국어 원본, `languages/en/script.json`은 독립 영어 대본이다. 영어 파일에는 문장·제목·화면 문구·배역·시간·게시 정보만 저장하고 공통 장면·자산은 원본을 참조한다. `/control`의 한국어/English 선택에서 빈 영어 문장도 직접 편집한다. 저장 전 작품 복원본을 만들고 버전 해시 충돌을 차단한다. 대본 편집으로 그림·팝업 구조·장면 순서·화자 ID를 바꾸지 않는다.

한국어 변경은 영어 문장을 덮어쓰지 않고 번역 대조 필요로 표시한다. 영어 확정은 유효한 한국어 대본 승인과 03의 한국어 완성 기준, 모든 발화 번역을 요구한다. 자동 번역 결과는 검토 전까지 확정본이 아니다. 새 승인은 도입·화면 문구·배역·타이밍까지 포함한 v2 해시를 쓴다. 기존 승인 기록을 자동 재발급하지 않는다. 언어별 이전 버전 복원은 다른 언어를 유지한다. 읽기용 문서·녹음 목록·SRT와 전체 대조하며 자연스러운 아동용 영어와 본문 충실도는 실제 사람이 검토한다.

실제 녹음 뒤 문장이 바뀌면 해당 MP3·SRT·타임라인·연기까지 다시 검토한다. ‘느리다’가 대사 후 대기 문제이면 문장을 줄이지 않는다. 음성 전에 적은 시간은 추정값이며 음성 실측이 아니다.

## 웹에서 직접 고치고 확인하기

`/control`에서 작품·언어·장면을 선택하고 미리보기를 재생한 뒤, **대본·장면 시간 편집**에서 문장을 고친다. **저장하고 미리보기 반영**을 누르면 복원본과 충돌 검사를 거쳐 저장하고 선택한 장면을 다시 불러온다. 다른 화면에서 먼저 저장했다면 입력 내용을 유지한 채 충돌을 알린다. 저장 중·완료·실패와 미저장 내용을 편집 영역에 표시한다. 문장이 바뀐 녹음은 교체 필요 상태이며 이전 음성을 새 문장에 연결하지 않는다. 기존 MP4는 별도 출력 전까지 이전 결과다.

장면 전체 시간은 책장 넘김을 제외한 초 단위(0.1~600초)로 입력한다. **자동 시간**은 직접 지정한 길이를 해제한다. 문장·동작 뒤 여유는 각각 0~10초로 조절한다. 입력한 전체 시간이 음성·읽기·필수 동작·지정 여유보다 짧으면 실제 적용할 최소 시간을 함께 표시하고 그 시간까지 재생한다. 늘린 시간은 장면 끝에 추가하며 기존 발화 시점과 동작 속도를 늘리지 않는다. 시간은 선택한 언어에만 저장된다. 내부 필드와 재생 규칙은 ANIMATION_GUIDE.md를 따른다.

## 수정 대본과 실제 음성의 전달

확정 문장을 바꾸기 전에 현재 문장·제안·이유·영향받는 발화 ID를 제시하고 기존 승인 범위와 대조한다. 오탈자·의미 수정안은 적용 여부를 구분해 기록한다. 대본 변경이 확정되면 먼저 완료한 대응 음성을 확보·대조한다. 승인된 신규 음성이 필요한 경우에만 HANDOFF의 완성 전 음성 요청·회신 계약을 따라 변경 한국어 발화 중 PC에 별도로 맡긴 것만 PC에 요청한다. 영어는 맥북의 직접 생성·연결·검수 절차를 따른다. 음성 요청용 확정 대본과 전체 싱크 검수 후의 완성본은 서로 다른 단계다. 화자가 이미 정정된 최신본을 오래된 요청 기록으로 되돌리지 않는다.

## 본문 검증과 영어 대본 승인 기록

장면/발화마다 성경 책·장·절, 확인한 번역본/출처·확인일, 본문의 사실/어린이용 재서술/추가 연출 구분, 의미 대조 결과를 남긴다. 본문에 없는 세부 설명은 성경 직접 인용으로 표시하지 않는다. 기존 한국어 문제는 원문과 근거·수정 범위를 기록하고 임의 윤문하지 않는다.

영어 검수본은 KO 기준 버전·해시, 장면/발화 ID, 한국어/영어 대응, 용어·발음표, 번역 누락/의미/쉬운 문장 검수 결과를 함께 제시한다. 사용자에게 이 구체적 검수본의 승인을 받은 후 영어 대본 해시·승인 시각·근거를 고정한다. 사용자가 웹에서 확인하도록 요청하면 영어 검토 대본을 기존 English 영역에 저장하고 실제 장면에서 확인하게 한다. 이 검토본 저장은 대본 승인·음성 완성·최종 배포 승인이 아니며 한국어 최종본을 보존한다. 대본 승인 전 음성 생성·완성 이벤트·완성본으로서의 운영 배포는 진행하지 않는다. 영어 음성 생성·웹 연결·자막/장면 타이밍 검수는 맥북의 이 대화에서 Codex가 담당한다. 수정된 영어 대본은 영향 부분을 재검수하고 새 승인을 받으며 한국어 원본을 보존한다.
