# 10~13 · 시리즈 운영과 유튜브 게시

브랜드는 열려라 성경동화, 제작자는 제작 · J.영이다. 어린이가 이해하고 즐기며 부모·교회학교 교사가 내용과 출처를 확인할 수 있는 한국어·영어 종이 팝업북 시리즈를 만든다. 제작 단계·화면·성우 규칙은 담당 전문 문서를 따른다. 이 문서는 게시와 운영만 다룬다.

## 1. 유튜브 패키징 — 시리즈 운영안

초기에는 하나의 채널에서 한국어판·영어판을 언어별 별도 영상으로 업로드한다. 재생목록은 ‘한국어 성경동화’와 ‘English Bible Stories’로 구분한다. 각 영상의 제목·설명·썸네일·자막은 해당 언어로 준비한다. 영상 제작 완료는 게시 완료가 아니다. ko/en 검수와 최종 승인·공개 승인은 독립적으로 진행한다. 실제 Public 전환은 각 영상의 09 승인과 사용자의 10 [유튜브 공개 게시] 버튼 클릭 후에만 수행한다.

아래는 운영 시작 기준이며 성과에 따라 수정한다. 추천 보장 공식이 아니다.

- 한국어 제목: `[이야기 인물·핵심 사건] | 어린이 성경동화 | 열려라 성경동화`. 영어 제목·설명은 어린이가 이해할 영어로 별도 작성하며 한국어 제목 양식을 그대로 남기지 않는다. 영문 브랜드 표기는 작품 기록의 확정값을 사용한다. 회차 번호는 핵심 이야기보다 앞세우지 않는다.
- 썸네일: 실제 작품의 핵심 인물·사건을 크게, 짧은 문구 한 개, 작은 브랜드 로고. 휴대폰 크기에서 읽히는지 확인한다.
- 썸네일에 앱 화면·재생 버튼·시간 막대·로딩·과도한 작은 글씨를 넣지 않는다. 공포·폭력 과장이나 실제 영상에 없는 장면으로 유도하지 않는다.
- 설명 첫 부분: 어떤 이야기인지, 어린이·가정·교회학교에서 어떻게 볼 수 있는지 자연스럽게 쓴다. 이어 성경 범위, 재서술 안내, 제작자, AI 음성 사용을 표기한다.
- 태그는 작품과 직접 관계있는 소수만 사용한다. 검색어 나열·무관한 인기 키워드·조회수 구매·억지 반복 재생을 쓰지 않는다.
- 아동 대상 작품은 실제 대상에 맞게 아동용으로 설정한다. 댓글·알림·카드·종료 화면을 이용하는 홍보 흐름을 전제로 만들지 않는다. 아동용 지정만으로 YouTube Kids 수록이 보장되지 않는다.
- 시리즈 재생목록과 채널 홈에서 작품을 정리한다. 한 편마다 독립적으로 이해할 수 있는 이야기와 결말을 갖춘다.
- 초기 작업 일정 제안은 1~2주에 한 편. 품질 유지가 우선이며 매일 업로드나 특정 시각을 노출 조건으로 주장하지 않는다.
- 첫 배포는 비공개로 화면·음량·자막을 검수한 뒤 09의 해당 언어 승인과 10의 사용자 공개 버튼 클릭에 따라 진행한다. 현재 계정 인증 제출과 채널 생성 완료를 혼동하지 않는다.

## 2. 게시 후 개선 기록

- 게시 7일·28일을 초기 점검 시점으로 제안한다. 이는 자동 예약이나 고정된 알고리즘 기준이 아니다.
- 노출, 노출 클릭률, 유입 경로, 평균 시청 지속 시간/조회율, 초반 및 장면별 이탈, 재방문 정보를 가능한 범위에서 기록한다.
- 절대 합격 클릭률을 임의로 정하지 않는다. 표본 크기·유입 경로·영상 길이가 비슷한 자료를 비교한다.
- 충분히 노출되는데 선택이 적으면 제목·썸네일을 점검한다. 초반 이탈이면 도입과 기대 일치를, 특정 장면 이탈이면 내용·템포·음성을 점검한다. 수치 하나로 원인을 단정하지 않는다.
- 한 번에 한 요소를 바꾸고 날짜·이전 값·변경 이유·관찰 결과를 남긴다. 잘 작동하는 제목을 이유 없이 계속 바꾸지 않는다.

## 3. 게시 기록
각 언어의 실제 public 상태·영상 ID·공개 재생 URL·확인 시각을 12에서 확인하고, 13에서 GitHub 원격 SHA와 웹 배포 버전/성공 상태를 별도로 기록한다. 요청 응답·업로드 완료·URL 문자열만으로 실제 공개 완료라고 하지 않는다. 실패를 완료로 기록하지 않는다.
HANDOFF.md 양식에 ko/en별 게시 설정·영상 ID·재생목록·검수 상태와 관찰 결과를 기록한다. 기술 명령과 인증 절차는 YOUTUBE_AUTOMATION.md를 따른다.
