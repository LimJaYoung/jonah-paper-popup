## 필수 제작 절차 v3.0과 구현의 구분

2026-10-12 지침 통합으로 한국어 제작/검수/완성 확정 → 영어 대본·음성 자동 제작 → 영어 실측 동기화 → 양언어 MP4/자동 검수 → 사용자 최종 검수/언어별 승인 → 사용자 공개 버튼 → 승인 영상 Public/실제 URL → GitHub·웹 상태/이력 → 보고 순서를 명시했다. 지침 반영은 구현 완료가 아니다.

- 실제 자연어 AI 실행은 차단 상태를 유지한다. 영어 자동 번역·실제 음성 자동 제작의 전체 연결과 검증은 미완료다. 기존 수동 영어 편집·음성 가져오기를 자동 제작 성공으로 표시하지 않는다.
- 자동 파일/일부 검사와 전체 시청·청취·사용자 최종 승인을 구분한다. 오류 수정과 승인 후 재검수의 전체 자동화 완료는 미확인이다.
- 언어별 최종 승인에 연결된 [유튜브 공개 게시] 버튼과 사용자 클릭 증거 검증은 현재 미구현/미확인이다. 기존 CLI 기능만으로 새 공개 절차를 충족했다고 보지 않는다. 실제 Public 공개·URL 검증도 별도다.
- 추가 유료 API·크레딧 구매·유료 음성 생성 금지와 작품별 승인 조건을 보존한다. 실행 경로가 없으면 해당 단계를 확인 대기/실패로 기록한다.

## 코드 조사 시 구분할 한계
- importer는 출처를 고정하지 않고 실제 입력값만 보관한다. SRT 문자열·길이 검사는 실제 음성 의미 청취와 다르다.
- 새 v2 대본 승인에는 openingNarration·voiceCasting·화면 문구·시간을 포함한다. 기존 승인 형식은 보존하지만 현재 전체 검수 기록을 자동 생성하지 않는다.

- 일반 TTS 명령은 Typecast 배역 자동 생성 기능이 아니다. AI 초안 화자 제한과 새 어댑터 지원은 실제 코드 확인이 필요하다.
