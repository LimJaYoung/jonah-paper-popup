# 01-B · 종이 그림과 화면 기준

제작 완료와 MP4 제작 인계 전에는 [디자인·애니메이션 공통 기준의 「최종 품질 검수 및 반복 개선」](DESIGN_ANIMATION_PROTOCOL.md)을 필수 적용한다. 세부 기준은 해당 원문에서만 관리한다.

작업 시작 시 [디자인·애니메이션 공통 기준과 이미지 미리보기](DESIGN_ANIMATION_PROTOCOL.md)를 실제 이미지와 함께 확인한다.

제작 순서·통과 조건은 `PRODUCTION_PLAYBOOK.md`의 01-B를 따른다. 특정 작품의 승인 원화·수치·배치는 해당 `STORY_RULES.md`에서 확인한다.

## 시리즈의 그림 기준

- 손으로 오린 종이와 얇은 종이 인형의 느낌. 종이 섬유·단면·앞뒷면·앞뒤 겹침과 접촉 그림자를 보여준다.
- 손맛이 있는 외곽선과 불규칙한 형태를 유지하되 깨진 알파 경계, 톱니, 흐림, 조각난 얼굴·수염은 허용하지 않는다.
- 승인된 요나 원화를 시리즈의 질감 참고로 실제 확인한다. 제한된 차분한 색을 유지하되 ‘전부 곤색’처럼 임의로 재해석하지 않는다. 현재 확정 원화의 색이 기준이다.
- 매끈한 일반 벡터 아이콘, 둥근 플라스틱 3D, 과도한 크레용, 화려한 색 추가, 네온·블룸·광택으로 바꾸지 않는다.
- 인물 얼굴·옷·신체 비율은 장면마다 유지한다. 정면·뒷면·팔 내림/올림·걷기와 작품에 필요한 자세를 같은 계열로 제작한다.
- 바닥·길·배경은 이야기를 돕는다. 불필요한 사각 판·이중 길·장식으로 책을 덮지 않는다. 새 장식으로 승인 화면을 임의로 바꾸지 않는다.

## 책과 오브젝트

기존 책 형태·비율·책등·접힘축·기본 재질·조명을 재사용한다. 공통 책 기본값은 기존 `book-core.js`와 요나 `app.js`를 실제 대조한다. 두 구현이 같다고 가정하지 않는다.

책의 위치·크기·카메라·각도는 고정한다. 모든 장면 소품은 해당 페이지에 부착한다. 인물·배·파도·구름·새는 책 안의 무대 범위에서 움직인다. 사용자 지정 V2 폭풍의 바람 선은 책 바깥에서 안으로 들어오는 환경 효과 예외이며 인물·배의 무대 이탈 허가는 아니다. 강조할 행동은 주변 움직임을 줄이고 원래 화면에서도 보이는 크기로 설계한다. 중간 확대·축소로 해결하지 않는다.

필요한 자세의 원화나 종이 부품을 준비한다. 한 장의 그림을 억지로 구부려 옷이 찢어지거나 팔이 뒤집히는 것을 허용하지 않는다. 새 인물에 요나 관절 좌표를 그대로 복사하지 않는다.

## 편집 중 요소 이동 — 높이 유지 (2026-10-13 확정)

- 모든 작품의 현재·추가 장면에 적용한다. 기본 요소를 위·아래·좌·우로 드래그할 때는 **페이지 표면으로부터의 높이를 유지하고 책 표면을 따라 위치만 이동**한다.
- 화면 아래로 드래그하는 동작을 높이를 낮추는 동작으로 해석하지 않는다. 나무·인물·소품이 땅이나 종이 밑으로 들어가거나 반대로 공중으로 떠서는 안 된다.
- 이동 기준은 요소가 붙은 페이지의 평면이다. 카메라를 향한 평면을 기준으로 높이까지 바꾸지 않는다. 키보드 방향키 이동에도 같은 원칙을 적용한다.
- 높이 변경은 사용자가 별도 높이 조절을 명시적으로 조작했을 때만 허용한다. 일반 위치 이동은 크기·회전·원래 애니메이션·페이지 부착과 접힘 구조를 바꾸지 않는다.
- 검수: 기본 나무 등 요소를 페이지 뒤쪽에서 앞 가장자리까지 드래그하고, 좌우 이동·되돌리기·저장 후 재진입에서도 높이가 유지되며 땅에 묻히지 않는지 확인한다. 페이지 전환 시에는 기존 부착·접힘 원칙을 유지한다.

## 공통 화면 요소

ko/en은 같은 그림·캐릭터·종이 구조·장면 순서·아동용 디자인을 공유한다. 제목과 그림/로고 안 글자·대사·자막·안내는 언어별로 관리하고 실제 화면에서 길이·줄바꿈·잘림·다른 언어 혼입을 확인한다. 영어 대사·자막에는 다른 언어가 섞이지 않게 한다. 다만 승인된 로고·타이틀 원화·J.영 표기는 이번 요청대로 재사용하며 영문 디자인으로 임의 교체하지 않는다.

| 요소 | 기준 |
|---|---|
| 영상 | 16:9, 최종 1920×1080 |
| 브랜드 | 열려라 성경동화, 승인 로고와 비율 유지 |
| 제목 | 작품 내용이 드러나는 제목; 로고와 위계 분리 |
| 책 | 중앙의 승인 구도, 모든 장면에서 같은 크기·위치 |
| 제작자 | 제작 · J.영의 승인 표기·원화·위치를 양언어에서 유지 |
| 자막 | 책 아래 한 곳, 음성과 일치, 자연스러운 줄바꿈 |
| 말풍선 | 영상에서 하단 대사와 중복 표시하지 않음 |
| 조작 UI | 웹 감상에는 유지, 출력 영상에는 미포함 |

절대 픽셀 수치는 승인 화면·작품별 기록으로 정한다. 요나 32px와 노아의 별도 자막 조정값을 공통 절대값으로 혼합하지 않는다. 기존 요나 구현 조사표는 `STORIES/01-jonah/IMPLEMENTATION_REFERENCE.md`이며 승인표가 아니다.

## 요나 제목 위치 (2026-10-13 확정)

- 사용자가 승인한 기존 제목 위치에서 아래로 **20px** 이동한다. 수치는 최종 영상의 **1920×1080 구성 좌표** 기준이다.
- 요나 공통 제목 영역의 상단 위치는 `14.8px → 34.8px`로 적용한다. 현재·추가 장면에서 같은 위치를 사용하고, 미리보기는 전체 화면과 함께 비례 축소한다.
- 웹 미리보기·캡처·집 PC 최종 출력에 동일한 배치를 적용한다. 제목 크기·가로 중앙 정렬·책·카메라·자막 위치는 이 변경으로 조절하지 않는다.
- 다른 작품의 승인된 별도 수치는 유지한다. 집 PC는 최신 제목 위치를 통합한 뒤 최종 영상에서도 확인한다.

## 대표 장면에서 확인할 것

원화 자체와 실제 책 위 크기에서 모두 확인한다. 인물 얼굴·작은 잎·소품이 읽히는지, 앞뒤면과 관절이 자연스러운지, 원화 비율이 변하지 않는지 확인한다. 페이지가 반쯤 넘어갈 때에도 종이 연결·받침·그림자가 따로 남지 않아야 한다.

승인 원화의 경로·버전과 대표 화면·사용자 확인 범위를 기록한다. 질감 참고 이미지와 승인된 출력 구도 이미지는 별개로 관리한다. 화면의 가로·세로를 다른 배율로 늘이지 않는다. 출력 비교는 `LAYOUT_PARITY.md`를 따른다.

## 건물·공통 자산과 고정 배치

건물·집·도시는 작품의 지역·시대와 승인 참고를 기록하고 기존 종이 재질·차분한 색·오린 윤곽을 유지한다. 공통 보관함 자산과 작품 승인 자산을 구분하며 등록만으로 장면 삽입 승인이 되지 않는다. 자산 ID·원본 경로·SHA256·출처/생성 기록·사용권·승인 범위·사용 장면을 기록한다. 재사용 시 원본을 보존하고 변형은 별도 버전으로 둔다.

로고·타이틀·만든이 J.영·하단 대사의 기준점·크기·여백은 작품의 승인된 1920×1080 구도에 고정한다. 영어가 길면 자막 영역 안의 자연스러운 줄바꿈과 읽기 시간을 조정하며 책·카메라·로고·타이틀·제작자 위치를 이동시키지 않는다. 구체 수치는 작품별 최신 승인 기준이며 새 수치를 추측하지 않는다. 웹 이야기 자막과 안내의 크기는 작품 규칙을 적용하고 영상 크기와 혼동하지 않는다.
