# 자연어 실행기 — ChatGPT 구독 전용 정책

## 기록의 적용 범위 · 2026-10-17 검수

아래 날짜별 구현·계정·음성 수·서버 상태는 해당 날짜의 조사 기록이다. 현재 운영 상태나 다른 환경에 그대로 적용하지 않는다. PC 로컬(`/control`, 127.0.0.1, 파일 저장)과 소유자 전용 Sites 웹(`/`, D1/R2)은 별도 환경이다. 웹 저장·배포가 PC에 자동 반영된다는 뜻이 아니다. 현재 여부는 해당 환경의 실제 코드·파일·접속 결과로 재확인한다. 최신 사용자 담당 지정과 PLAYBOOK을 우선한다. 이 검수는 문서 대조이며 PC 실행·계정 상태·전체 영상 품질 재검증이 아니다.

2026-10-11. 이 문서는 이전 API 키 설정 안내를 대체합니다. 최종 서버는 Windows 데스크톱이며 현재 노트북은 로컬 개발·검증용입니다.

## 지금 실제로 동작하는 것

- 웹은 공식 Codex app-server의 initialize → account/read → account/rateLimits/read만 호출해 ChatGPT 로그인·사용 한도를 확인합니다. 현재 채팅을 원격 조작하지 않습니다.
- API 키와 토큰을 읽어 전용하거나 브라우저로 보내지 않습니다. 응답에는 로그인 유형, 플랜, 사용률·초기화 시각과 차단 이유만 있습니다. 이메일·계정 ID·크레딧 잔액은 보내지 않습니다.
- 기존 유료 Responses API 공급자는 제거했습니다. OPENAI_API_KEY를 설정해도 웹 자연어 기능은 켜지지 않습니다. 자동 API 전환, 크레딧 구매, 무료 리셋 사용, 외부 결제·게시 경로가 없습니다.
- 한도 도달, 한도 조회 실패, API 로그인, 크레딧 사용 경계 미확인은 차단합니다. 요청은 `blocked`로 기록하고 성공·담당 작업 대기로 바꾸지 않습니다. 차단 시 모델 호출·작품 변경·렌더링은 없습니다.
- 기존 수동 문장/시간 편집, 타임라인·자막 준비, 보유 이미지·음성을 사용하는 로컬 검수 MP4는 그대로 사용할 수 있습니다.

## 아직 작동하지 않는 핵심 기능

**구독 기반 자연어 자동 수정은 미완료입니다.** 공식 Codex는 ChatGPT 로그인으로 별도 비대화형 작업을 실행할 수 있지만, 현재 앱은 계정 조회까지만 연결합니다.

이 계정은 잔여 구독 한도와 별도로 크레딧 사용 가능성이 보고됩니다. 공식 설정·프로토콜 문서에서 한 번의 실행 도중에도 구독 한도 초과 크레딧 사용을 금지하는 설정을 확인하지 못했습니다. 실행 전 사용률 검사나 짧은 시간 제한만으로 과금 상한을 보장한다고 주장하지 않습니다. 크레딧 잔액이 없더라도 CLI의 전체 도구 제한과 Windows 동작이 검증되기 전에는 모델 실행을 열지 않습니다. 사용자가 단순히 환경변수로 이 차단을 해제하는 옵션은 없습니다.

다음 구현에는 (1) 서버 측에서 구독 초과 크레딧 사용을 차단하는 공식 보장, (2) 비밀·외부 파일·셸·연결 도구 접근 제한 검증, (3) 기존 작품 복사본의 실제 자연어 수정→렌더→검수 1건이 필요합니다. 렌더러나 테스트 수정안만 통과한 것을 자연어 성공으로 세지 않습니다.

## 실행과 Windows 이전

기존 START-WINDOWS.cmd 및 DEPLOYMENT/WINDOWS.md의 로컬 서버 실행 방법을 따릅니다. Node·Chrome·FFmpeg 환경은 기존 안내와 같습니다. 이 변경은 자동 설치나 외부 공개를 하지 않습니다.

Windows에서는 공식 Codex의 **ChatGPT 로그인**을 `codex login status`로 확인합니다. API 키 로그인은 사용하지 않습니다. npm 공식 패키지 안의 native codex.exe도 탐색합니다. 필요하면 `STUDIO_CODEX_PATH`로 공식 실행 파일을 명시하며 .cmd를 임의 셸로 실행하지 않습니다. 2026-10-12 실제 CLI 0.130.0, ChatGPT Pro 로그인·구독 한도 조회를 확인했습니다. `app-server --listen stdio://`의 initialize/account/read/account/rateLimits/read만 호출합니다. 계정 조회는 모델 추론이 아닙니다.

현재 계정은 creditsAvailable=true이며 구독 사용량만 허용하는 강제 경계가 확인되지 않았습니다. `credit_boundary_unverified`로 대기하며 실행 차단 조건을 제거하지 않았습니다. 모델 도구 격리도 검증 전입니다. 따라서 실제 자연어 작업 생성→파일 수정(C)을 통과했다고 보고할 수 없습니다. 이 조건을 해결하기 전에는 승인 범위 내 직접 개발과 수동 검수만 진행하며, 비용 승인이 이미 있는 것으로 추정하지 않습니다.

노트북에서는 설치된 ChatGPT 앱의 공식 CLI를 발견합니다. 계정 조회는 15초 제한, 화면 조회는 60초 캐시, 실행 버튼에서는 새로 조회합니다. 로그인/사용량 변경 후 최신 내용 다시 불러오기로 확인합니다. 웹 주소는 `http://127.0.0.1:5180/control`이며 컴퓨터 내부 접속만 허용합니다.

## 기존 작업 보존

원본 STORIES, 이미지, 음성, 최종 MP4는 이 변경에서 수정하지 않습니다. 이전 AI 작업의 복사본·검수 결과·복원본은 보존합니다. 적용 전 파일·지침 해시 충돌 검사도 유지합니다. 원본 MP4는 문장 수정만으로 갱신되지 않습니다. 이전 API 관련 문서는 당시 검증 이력이며 현재 실행 설정은 이 문서가 담당합니다.
