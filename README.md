# 요나의 종이 팝업북 — 첫 번째 장

## 실행

Node.js 20 이상에서 `npm run dev` 후 http://localhost:5173 접속. 별도 패키지 설치나 외부 CDN 없이 실행한다. `npm run check`는 JS 구문을 검사한다.

## 작업 시작 시 상태

연결된 작업 폴더에는 `.git`만 있었고 기존 구현·분리 소재가 없었다. 그래서 이 폴더에 Three.js 0.180.0 기반 첫 장면을 새로 만들었다. Three.js 배포 파일 및 라이선스를 vendor/에 포함했다.

## 구현

- 책 한 권. 두꺼운 청록 표지, 12겹 페이지 가장자리, 크림 내지, 금색 표지 인쇄.
- 책등의 고정 회전축과 페이지 안쪽 수납 간격. 왼쪽 표지가 열리며 바닥에 놓인 펼침 상태로 전환.
- 앞·중간·뒤 파도는 각각 두 페이지에 붙은 별도 종이 패널. 고래에는 넓은 실루엣을 책 안으로 접는 보조 세로 접힘선이 있다.
- 배와 요나는 오른쪽 페이지에 별도 부착. 선체 앞판을 한 층 더 두어 요나가 선체 안에 보이도록 구성.
- 이미지 알파를 따르는 얇은 절단면, 앞면/뒷면, 알파 그림자. 전체 참고 이미지를 평면 하나로 표시하지 않는다.
- `progress` 하나로 모든 회전값을 계산. 뒤→중간→앞 순의 시차. 펼치기/접기/다시 재생/일시 정지 및 터치·키보드용 range 슬라이더.
- 펼침 마지막 구간에만 작은 강체 회전. 정점 변형이나 물 시뮬레이션은 없다. 카메라는 고정되며 화면 비율에 따라 거리만 맞춘다.
- 운영 코드 app.js, 화면 index.html/style.css, 로컬 서버 server.mjs.

## 소재의 출처와 남은 디자인 작업

첨부한 확정 참고 이미지를 바탕으로 내장 ImageGen을 사용해 5개의 분리 PNG를 새로 제작했다. 원본에서 정확하게 추출한 오브젝트가 아니며 원본의 가려진 형태를 정확히 복원했다고 주장하지 않는다. 앞/뒤 파도는 같은 원화를 크기와 위치를 달리하여 사용하고 중간 파도는 별도 원화다. 뒷면은 원본에 없으므로 크림색 종이로 재구성했다.

원본과 완전히 같은 윤곽과 디테일을 확정하려면 원본 제작자의 파도 3층·배·고래·요나 개별 투명 원화(가려진 영역 포함), 뒷면 디자인 또는 무지 뒷면 승인, 실제 접지 도안이 필요하다. 현재 구현은 작동하는 첫 장면이며 이 소재를 원본과 동일한 최종 원화라고 표시하지 않는다.

종이의 접힘은 설계한 강체 키네마틱 모형이다. 실제 제본용 팝업 구조의 물리 시뮬레이션이나 모든 종이 사이의 연속 충돌 해결기는 아니다. 최종 인쇄·제작용 접지 도안으로 사용할 수는 없다.

## 브라우저 검수

Codex 내장 브라우저에서 0/50/100% 상태를 직접 확인했고 1440×1000, 390×844, 320×740 반응형 화면을 검수했다. 고래 접힘 분리, 요나 가림, 모바일 좌측 잘림, 표지 인쇄 방향을 수정했다. 접기 버튼의 0% 도달, 다시 재생 시작, 일시 정지 유지와 재개, 슬라이더 직접 조작을 확인했다. 실행 중 브라우저 콘솔 오류 없음. 캡처는 captures/ 아래에 저장한다. 실제 모바일 기기의 터치 하드웨어 테스트는 별도로 남는다.

다음 이야기 장면은 구현하지 않았다.

## 배포

`npm run build`로 실행 파일만 `dist/`에 모은다. `npm run deploy`는 빌드 후 기존 `gh-pages` 브랜치에 결과물을 커밋·푸시한다. GitHub Pages는 이 브랜치의 루트에서 배포한다. 서버 코드, 작업 기록, 검수 캡처는 사이트에 포함하지 않는다. `main` 푸시만으로는 사이트가 갱신되지 않으므로 변경 후 `npm run deploy`를 실행한다. GitHub에 푸시 가능한 Git 인증이 필요하다.
